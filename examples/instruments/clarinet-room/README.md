# Clarinet and shared-room comparison

before.wav uses the preserved Misty 5 render; after.wav uses Misty 6. Both cover seconds 14–44, matched to -25 dBFS RMS with 10 ms edge fades and no compression or limiting. RMS matching is approximate, not perceptual LUFS.

The musical arrangement is unchanged. Misty 6 uses the updated clarinet and a shared small room: clarinet send 0.70, piano 0.45, upright bass 0.08, wet return 0.32. This comparison combines the instrument and acoustic changes; it does not isolate their individual effects. The original full render is preserved as misty5-before.wav because re-rendering old scores uses the new clarinet.

Technical validation does not establish a listening preference.
