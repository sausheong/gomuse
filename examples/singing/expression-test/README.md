# Sun in My Shoes: expressive chorus audition

Run `render.py` with the local singing virtual environment to render both versions. Uses the existing Leif Lush model and lower-register chorus. The original full song is unchanged.

The expressive version holds each final word an extra 230 ms, retains a breath before the next line, introduces 35-cent upward arrivals on selected accented words, and adds delayed 17-cent, 5.2 Hz vibrato to the extended endings. Pitch changes are applied before acoustic synthesis. A smooth post-render gain envelope accents important words and relaxes releases. No model change or emotional conditioning is claimed.

Both clips are dry mono PCM16, 44.1 kHz, 15.6 seconds, RMS-matched with no clipping. The comparison tests the combined performance treatment; perceived expressiveness requires listening feedback. Input plans, raw output, pitch diagnostics and metrics are retained here.
