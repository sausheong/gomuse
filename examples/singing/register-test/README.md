# Leif Lush register comparison

Two fresh renders of the same 17-note Beyond the Sea excerpt using GoMuse's DiffSinger adapter, Leif Lush, neural prosody, expression 1, seed 42 and 20 steps. Only the requested MIDI pitches change: original C4–D5, octave lower C3–D4. Lyrics, note timing and all other input settings are identical. This is resynthesis at lower pitches, not pitch-shifting an audio file. Model-predicted durations and expression may respond to the changed pitches.

The WAVs are RMS-matched over a common singing window using constant gain; no effects or compression. Both are mono 44.1 kHz, 15.56 seconds. See metrics.json. Input JSON and raw renders are retained. These are fresh controlled adapter renders, not the earlier OpenUtau comparison. Perceptual quality awaits listening feedback.
