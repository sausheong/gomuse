# Synthesizer V chorus comparison

Prepared 32-note MIDI with embedded lyric events, tempo 128 BPM and the same lower-register chorus melody. lyrics.txt is provided if the importer does not retain lyric events. MIDI starts with a 300 ms lead-in and preserves note times to the nearest tick. No artificial scoops, vibrato or volume boosts from the earlier experiments are included.

Import into Synthesizer V Studio 2 Pro trial, select an available English male voice, and compare its default performance with a suitable expressive vocal mode. Exact voice and modes will be selected from the installed trial. Render dry audio and level-match before comparing with Leif. This folder currently contains preparation files only; a Synthesizer V vocal has not yet been rendered.
